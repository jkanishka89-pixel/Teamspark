# 🚀 TeamSpark AI
> **Hackathon 5.0 | Round 1 Submission**  
> *From "Who do I know?" to "Who fits best?"*

## 🧐 The Problem
Great ideas die without a team. 
- **68%** of students don't know who has the right skills.
- Teams are formed by **luck**, not by fit.
- **Skill gaps** lead to abandoned projects.

## 💡 The Solution
**TeamSpark** is an AI-powered team finder that matches students with the right hackathon teammates based on:
1. **Skill Complementarity** (Do we fill each other's gaps?)
2. **Interest Alignment** (Do we care about the same themes?)
3. **Experience Mix** (Do we have the right balance of seniors/juniors?)
4. **Reliability** (Will they show up?)

## 🛠️ Tech Stack
- **Frontend**: Streamlit (Interactive Dashboard)
- **Backend Logic**: Python (Pandas, JSON)
- **Visualization**: Plotly (Radar Charts, Histograms)
- **Data**: Synthetic Ecosystem Dataset (500+ Personas)

## 📊 The Dataset
This repo includes a high-fidelity synthetic dataset designed to simulate a real university ecosystem:
- `students.json`: 500+ student profiles with skill vectors, personalities, and reliability scores.
- `events.json`: 30+ hackathon events with specific role requirements.
- `matches.json`: 200+ AI-generated match scores with explainable breakdowns.
